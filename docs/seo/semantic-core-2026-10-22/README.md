# Семантическое ядро DEERE-SHOP: Россия, Wordstat, 22.10.2026

Рабочая версия ядра для каталога запчастей John Deere. Источник чисел — непосредственно интерфейс [Яндекс Wordstat](https://wordstat.yandex.ru/), регион Россия (225), все устройства. Собрано 88 отчётов, включая 14 измерений с кавычками. Данные сверены с публичным ассортиментом deere-shop.ru. Группировка предварительная, по смыслу и типу страницы: подтверждённой кластеризации по пересечению поисковой выдачи пока нет.

Получено 707 наблюдений строк и 604 разные формулировки в таблицах. Ещё два запроса добавлены из замеров с кавычками: всего 606 уникальных формулировок. Из них 308 исключены, а 298 оставлены в рабочем наборе из 34 групп. Внутри рабочего набора 46 запросов привязаны к существующим категориям/каталогу, 20 — к проверенным карточкам, 226 требуют проверки и 6 относятся к пробелам в структуре. Таким образом, **66 назначений уже подготовлены для редакторской работы**, а 232 строки остаются исследовательским резервом. Ни число 606, ни число 298 не означает столько готовых запросов к внедрению.

- `cluster-map.html` — автономная интерактивная таблица с поиском и фильтрацией по группе и статусу; открыть локально в браузере.
- `measurements.csv` — все исходные измерения: фраза с операторами, период, общее число запросов, ссылка на отчёт.

Смысл статусов важнее количества строк: запрос с неподтверждённым соответствием ассортименту остаётся на проверке. Это не готовое задание на массовое создание посадочных страниц.

## Как читать частотности

Видимые строки популярных запросов и общее число в заголовке отчёта сохранены как разные показатели. Заголовок широкого запроса включает расширения; он не является точной частотой введённой фразы. Значения разных строк также могут пересекаться. **Складывать их в «размер рынка», прогноз посетителей или число потенциальных заявок нельзя.**

В замерах с кавычками берётся именно число из заголовка. Кавычки ограничивают количество слов, но не фиксируют порядок слов и словоформы. Поэтому соответствующий столбец не называется точной частотой. Числа строк, которые Wordstat продолжал показывать внутри таких отчётов, не используются как частота с кавычками. Правила: [операторы Wordstat](https://yandex.ru/support2/wordstat/ru/content/operators), [описание отчётов](https://yandex.ru/support2/wordstat/ru/interface/new).

Во время сбора Wordstat показывал предупреждение о временной недоступности части данных. Большинство таблиц содержали период **08.09.2026–07.10.2026**; ряд отчётов с пустой таблицей — **21.09.2026–21.10.2026**. Период хранится отдельно для каждого показателя. Пустая таблица не заменяется нулевой частотой. Если интерфейс явно показал ноль в заголовке, это отдельное наблюдение соответствующего периода, а не доказательство отсутствия спроса вообще.

Первый скачанный CSV оказался только заголовком с другим периодом. Он сохранён в `raw/wordstat-01.csv` как непригодный экспорт и не участвует в расчётах. Рабочий источник — сохранённые видимые строки интерфейса. В режиме «Похожие» полезные строки не были получены; это ограничение охвата, а не нулевой смежный спрос.

## Привязка к сайту и пробелы

1. **Общий коммерческий спрос на запчасти:** основной владелец кластера — `/catalog`. Главная поддерживает предложение по поставке и подбору и ведёт в каталог. Существующий родительский раздел `/catalog/zapchasti-john-deere` требует отдельной проверки роли: не назначать ему те же основные запросы одновременно. Эта рекомендация не является разрешением на изменение URL или редиректы.
2. **Фильтры:** подтверждён спрос и проверены отдельные карточки, но выделенной категории нет. Пока использовать проверенные карточки и соответствующие существующие разделы. Отдельную подборку/категорию рассматривать после проверки полного ассортимента, намерения в выдаче и согласования структуры. Не создавать автоматически страницу на каждый вариант запроса.
3. **Ремни, электрика, охлаждение, двигатель и остальные узлы:** связать соответствующие группы с существующими категориями. Подгруппы внутри одного раздела не означают, что каждой нужна новая страница. P1 означает редакторский приоритет при проверенном назначении, а не прогноз продаж.
4. **Parts Catalog, онлайн-каталог, схемы и PDF:** намерение часто смешанное. Уже есть статья `/articles/parts-catalog-john-deere-kak-polzovatsya`; использовать её как кандидата для справочного намерения. Коммерческое намерение может принадлежать `/catalog`. Окончательно распределить запросы после проверки выдачи Яндекса; не обещать собственный официальный электронный каталог или файлы, которых нет.
5. **Модельные запросы:** спрос на 8430, 7830, 1890 и другие модели обнаружен, но сам запрос не подтверждает применяемость товаров. Страницу по модели можно обосновать только проверенной подборкой деталей. Не выводить совместимость из названия модели в запросе.
6. **Артикулы:** точное совпадение с SKU из Product JSON-LD позволяет предложить существующую карточку. RE509672 и RE541922 обнаружены в URL карточек, но фактические SKU — RE509672A и RE541922A. Это кандидаты на проверку, а не подтверждённые замены. F681170, AT387534 и F071312 не найдены в текущем sitemap; не объявлять их отсутствующими в бизнесе вообще.
7. **Статьи:** часть текущих материалов пересекается по теме поиска артикула и подготовки данных для подбора. Перед новыми публикациями распределить основные запросы между существующими статьями и проверить поисковое намерение. Не создавать ещё одну статью с тем же обещанием только ради варианта формулировки.

Диагностические формулировки о снятии форсунок, засорении сетки и пробитой прокладке оставлены на проверку без целевой страницы. Кириллические обозначения моделей также считаются указанием на модель и не получают готовую категорийную привязку. Запросы на игровые моды исключены; скачивание каталога запчастей без подтверждённого коммерческого намерения остаётся на проверке.

## Как применять ядро

Первый пакет — проверенные товарные карточки с артикульным спросом и существующие категории с коммерческими запросами. Для каждого изменения редактор берёт один целевой URL, проверяет назначение и факты о товаре, затем обновляет подходящие SEO-поля и полезный текст в Directus. Название, артикул, применяемость, цена, остаток и сроки поставки требуют собственных подтверждений. Частотность ничего из этого не подтверждает.

Для групп со статусами `needs_review`, `content_gap` или эквивалентной пометкой сначала проверить фактический ассортимент и выдачу. Полных региональных top-10 для сравнения пересечения URL в этой работе не получено, поэтому метод группировки во всех группах — `intent_only_provisional`. Не выдавать её за кластеризацию по SERP.

Перед отдельным контентным выпуском объявить коллекции, записи и поля по ADR-002. Редакторские правки публикуются через CMS с ревалидацией только затронутых маршрутов. Создание новых категорий, модельных страниц или изменение маршрутов — отдельная задача со своей областью изменений.

После восстановления полноты Wordstat повторить приоритетные замеры в одном периоде, расширить коммерческие хвосты и проверить сезонность. Затем дополнить ядро фактическими запросами из Вебмастера и данными по продажам/заявкам при наличии доступа. Сезонность, конкурентность, реальные позиции, конверсии и поисковые показы сайта здесь не измерены. Все 12 971 SKU отдельно не проверялись: товарная сверка относится к 47 явно указанным примерам.


Она проверяет данные и их происхождение; не заменяет проверку работы сайта. Продуктовые тесты и деплой для этого исследовательского выпуска не требуются: исходники приложения и CMS не меняются. Локальное правило `.gitattributes` сохраняет байты файлов исследования при переносе между Windows и Linux. Это необходимо для воспроизводимости контрольных сумм исходных наблюдений и производных файлов.
