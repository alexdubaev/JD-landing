## Как исполнять

1. **Читать сначала:** `AGENTS.md` и
   `docs/decisions/ADR-002-scope-locked-changes-and-content-only-releases.md` — они главнее всего.
2. Одна задача = один ревьюнутый коммит = файлы только из раздела «Allowed files» этой задачи.
   Перед коммитом сверять `git diff --name-only` со списком.
3. Рефакторинг — по TDD: характеристический тест из раздела «TDD-план» пишется до правки.
4. «Не делаем» в конце каждой задачи — это граница, не предложение. Оверинжиниринг запрещён.
5. Порядок: **P1** (TD-01 первым — CI, затем TD-02…TD-06 независимо) → **P2** (TD-07 → TD-08
   (+TD-19) → TD-09 → TD-10; параллельно TD-11, TD-12; затем TD-13 строго после TD-06) →
   **P3** (TD-15…TD-18 в любом порядке). Полный граф зависимостей — в README.
6. Проверки локально: `frontend/` → `npm test && npm run lint && npm run typecheck`;
   `seo-worker/`, `directus/` → `npm test`; из корня → `node --test deploy/ scripts/`.
