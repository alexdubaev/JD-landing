Пакет данных товаров для сайта

products.xlsx — таблица для просмотра и ручной проверки.
products.csv — импортная таблица в UTF-8.
products.json — готовый массив объектов для программного импорта.
images/ — исходные фотографии, разложенные по группам прайсов.

Поля:
sku — идентификатор товара из исходного объявления;
title — название товара;
description — полное описание;
price — стоимость из исходного прайса;
main_image — первое изображение товара;
gallery — список всех изображений товара.

Пути изображений относительны корня этого пакета.
