# scripts/archive

Выполненные или замещённые скрипты. Не запускать без явного решения владельца.

- `build-directus-products-csv.mjs`, `import-directus-products-csv.mjs` —
  первый пайплайн загрузки каталога (CSV build + import). Замещён
  field-level импортёром `directus/importer/` (идемпотентный, с rollback и
  тестами). Известные проблемы архивной версии: дубли CSV/env-парсеров,
  расхождение BOM-конвенций, захардкоженный входной путь и латентный баг в
  regex проверки многоточия — сознательно не чинятся.
